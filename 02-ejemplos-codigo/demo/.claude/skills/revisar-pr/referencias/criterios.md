# Criterios de gravedad

Se lee en el paso 4 de la skill, no antes.

| Gravedad | Qué es | Ejemplo |
|---|---|---|
| **Bloquea** | Rompe un criterio de aceptación, encoge la red sin que cambie la especificación o toca una zona vetada sin avisar | Borra un test para que pase la suite |
| **Importante** | Funciona, pero deja el código peor de lo que estaba: duplicación, frontera cruzada, complejidad sin tests | Una vista que llama a la API |
| **Menor** | Nombres, estilo, comentarios. Si lo puede decir un linter, no lo digas tú: propón la regla | Un nombre poco claro |
